About This Project

A hands-on demonstration of a complete DevOps lifecycle

Project Purpose

This project was built to demonstrate a real, end-to-end DevOps workflow — from writing application code to deploying it on cloud infrastructure. It covers the core responsibilities of a DevOps Engineer: application development, containerization, continuous integration, infrastructure automation, and Linux server deployment.

How It Works

  1. The Flask application is developed and tracked with Git.
  2. Code is pushed to a GitHub repository.
  3. GitHub Actions automatically runs a CI pipeline: installing dependencies, running checks, and building the Docker image.
  4. Terraform provisions an AWS EC2 instance and security group.
  5. The Docker container is deployed and run on the EC2 instance, making the app publicly accessible.

Why This Project Matters
